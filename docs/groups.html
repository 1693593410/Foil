API

坐标是像素，Y 向下。库不推动物体。边贴着不算重叠。矩形不旋转。编号要能放进 32 位，4294967295 可以用。

Coordinates are pixels, Y down. The library does not move bodies. Touching edges is not an overlap. Rectangles do not rotate. An id has to fit in 32 bits; 4294967295 is allowed.

创建Create

new

CPU，精度 f32，查询线程上限 16。

CPU, f32, query thread cap 16.

let world = Foil::new();
world = Foil.Foil()
world = Foil.Foil(backend="cpu", real="f32", threads=16)

open

按后端创建，精度是 f32。名字可以是 cpu、dx12（也认 d3d12、directx12）、vulkan、metal、gl（也认 opengl、gles、angle），以及 wgpu、webgpu、gpu。显卡查询是实验功能，传输开销目前大于收益。

Create with a backend, in f32. Names: cpu, dx12 (also d3d12, directx12), vulkan, metal, gl (also opengl, gles, angle), and wgpu, webgpu, gpu. GPU query is experimental; transfer cost currently outweighs the gain.

let world = Foil::open("dx12")?;
world = Foil.Foil("dx12")

open_with

real 写 f32 或 f64。f64 只能配 cpu，否则返回错误。Python 用构造参数，没有单独的这个函数。

real is f32 or f64. f64 only pairs with cpu; anything else returns an error. Python passes this to the constructor and has no separate function.

let world = Foil::open_with("cpu", "f64")?;
world = Foil.Foil(backend="cpu", real="f64")

backend

创建时选定的后端名字。一次查询改走 CPU 时，这个字符串不变。

The backend name chosen at creation. It stays put when one query falls back to the CPU.

world.backend()
world.backend()

real

返回 "f32" 或 "f64"。

Returns "f32" or "f64".

world.real()
world.real()

threads

当前上限。写多少就用多少。0 表示用进程里现成的线程池，按那台机器的逻辑处理器数拆开。被查物体少于 192 个时始终单线程。

The current cap. The number you set is the number used. 0 uses the process thread pool and splits by the machine’s logical processors. Fewer than 192 queried bodies always run on one thread.

world.threads()
world.threads()

set_threads

改上限。1 始终单线程。下次批量查询才按新的数量建池。

Change the cap. 1 stays single-threaded. The next batch query builds the pool at the new size.

world.set_threads(0);
world.set_threads(0)

物体Bodies

add

放进一个物体。x y 是中心，w h 是宽高。圆的半径是宽高里较大的一半。shape 只接受 rect 和 circle。形状写错，或编号放不进 32 位，返回错误，物体不会放进去。sensor 为真时只参与检测。mask == 0 碰上所有人，对方 group == 0 也碰上。0 不是「谁都不碰」。

Insert a body. x y is the center, w h the full size. A circle’s radius is half the larger side. shape accepts only rect and circle. A bad shape, or an id that does not fit in 32 bits, returns an error and inserts nothing. sensor true means detection only. mask == 0 meets everyone, and so does the other body’s group == 0. 0 does not mean “meet nobody.”

world.add(id, x, y, w, h, "rect", false, group, mask)?;
world.add(idx, x, y, w, h, shape="rect", sensor=False, group=0, mask=0)

remove

按编号删掉。编号不在世界里时什么也不做。

Remove by id. A missing id does nothing.

world.remove(id);
world.remove(idx)

clear

清空全部物体和格子。

Remove every body and the grid.

world.clear();
world.clear()

set_pose

改中心。不存在的编号会被忽略。

Move the center. A missing id is ignored.

world.set_pose(id, x, y);
world.set_pose(idx, x, y)

move_by

沿这一帧的位移贴着别的实体滑，新中心直接写进世界。先水平，再竖直。空地上每轴只扫一次格子。边贴着可以停。起点已经叠在别人身体里时，推到更近的贴边。传感器不挡人，自己也不会被挡住。返回写进去的中心。编号不存在时返回 (0, 0)，世界不变。

Slide by this frame's displacement and store the new center. Horizontal first, then vertical. In open space each axis scans the grid once. Touching an edge is allowed. A center that already overlaps another body is pushed to the nearer touching edge. Sensors do not block and are not blocked. Returns the stored center. A missing id returns (0, 0) and changes nothing.

let (x, y) = world.move_by(id, dx, dy);
x, y = world.move_by(idx, dx, dy)

pose

读中心。编号不存在时返回 None。

Read the center. Returns None when the id is missing.

let (x, y) = world.pose(id)?;
xy = world.pose(idx)

set_size

改宽高。Rust 的形状参数在尺寸前面，空字符串表示沿用现在的形状。Python 的形状在最后，默认也是空字符串。形状名写错才返回错误。

Change width and height. In Rust the shape argument comes before the size; an empty string keeps the current shape. In Python the shape is last and defaults to an empty string. Only an unknown shape name returns an error.

world.set_size(id, "circle", w, h)?;
world.set_size(idx, w, h, shape="")

size

读宽高。编号不存在时没有结果。

Read width and height. No result when the id is missing.

let (w, h) = world.size(id)?;
w, h = world.size(idx)

set_sensor

改成传感器或实体。传感器互相看不见，实体仍能看见传感器。

Turn the body into a sensor or a solid. Sensors do not see each other. A solid still sees sensors.

world.set_sensor(id, true);
world.set_sensor(idx, True)

查询Queries

overlaps

用它存着的位置，返回重叠到的编号。边贴着不算。传感器不会列出别的传感器。

Using its stored position, return the overlapping ids. Touching edges do not count. A sensor does not list other sensors.

let hits = world.overlaps(id);
hits = world.overlaps(idx)

overlaps_at

临时放到 (x, y) 再查，不改存着的坐标。

Query as if it were at (x, y), without storing that position.

let hits = world.overlaps_at(id, x, y);

Python 没有这个方法。

Not wrapped in Python.

query

一次查很多个编号。结果是 (被查询的编号, 对方)。两边都在名单里时，两个方向都留。选了显卡且精度是 f32 时先走显卡，查不了再整次改走 CPU。显卡路径是实验功能。

Query many ids at once. Each result is (queried id, other id). When both ids are in the list, both directions are kept. With a GPU backend and f32, the GPU runs first; if it cannot, the whole query uses the CPU. The GPU path is experimental.

let pairs = world.query(&ids);
pairs = world.query(ids)

query_many

和 query 同一套 CPU 检测，把结果追加进你给的 Vec。不走显卡。

The same CPU detection as query, appending into a Vec you pass. It does not use the GPU.

world.query_many(&ids, &mut pairs);

Python 没有这个方法。用 query。

Not wrapped in Python. Use query.

hit

问这两个编号在给定中心上是否重叠。分组和形状都算，位置由参数给出。

Whether these two ids overlap at the given centers. Groups and shapes count. The positions come from the arguments.

world.hit(a, ax, ay, b, bx, by)

Python 没有这个方法。

Not wrapped in Python.
